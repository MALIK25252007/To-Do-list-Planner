### 📝 About

A clean, minimal **daily to-do planner** that helps you stay on top of your tasks. Add tasks on the fly, mark them complete, track your progress for the day, and clear completed items in one click. No sign-up, no clutter — just a fast planner that opens in your browser.

### ✔️ Features

- [x] Quick add tasks with one click
- [x] Mark tasks as completed
- [x] Live task & completion counter
- [x] "Clear Completed" to tidy your list instantly
- [x] Fully responsive — works on mobile and desktop
- [x] No login, no backend, no dependencies
